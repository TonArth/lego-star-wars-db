# LEGO Star Wars - 90 Figurine Interactive Database

Database interactiv cu 90 de figurine LEGO Star Wars, organizate în 10 seturi tematice, cu linkuri directe către BrickLink pentru fiecare personaj.

## Live

Vezi pagina live pe GitHub Pages (link generat după activare).

## Conținut

- 10 seturi tematice (Jedi, Clone Troopers, Mandalorieni, Sith, Eroi, Vânători de recompense, etc.)
- 90 de figurine unice, fiecare cu preț estimativ UK și link BrickLink
- Interfață cu tab-uri, responsive design
